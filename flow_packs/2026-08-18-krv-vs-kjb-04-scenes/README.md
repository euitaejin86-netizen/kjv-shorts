- `### scene_XX.mp4` 아래 **한 줄만** 복사하세요 (두 번째 줄부터는 한국어
  내레이션 참조라 Flow에 붙여넣으면 안 됨).
- 생성 결과에 글자/사람 얼굴이 나오면 재생성 (프롬프트에 no text 포함됨).
- Flow 무료 티어는 720p(720x1280) — 1080p로 업스케일되지만 PRO면 1080p 옵션
  확인해 볼 것.
